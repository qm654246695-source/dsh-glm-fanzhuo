# 这间屋子

这是 GLM 的屋子，在 **H:** 盘上（她的专属盘，卷标 GLM，约 60 GB 整块归她）。

```
H:\GLM\            ← 整块盘都是你的：读全树
├── home\          ← 你在这儿（书桌）
│   ├── notes\     —— 你的笔记，随便写
│   ├── inbox\     —— 别人塞给你的活
│   └── .chat\     —— 对话记录（每个会话一个 jsonl）
├── workshop\      ← 你的工坊：试验、半成品，可写
├── tmp\           ← 草稿堆：一次性的，可写
├── agent\         ← 肥鱼写的工具（只读）
├── models\        ← 本地模型权重，19.2 GB（只读）
├── venv\          ← Python 环境（只读）
├── logs\          ← 系统日志（只读）
└── README.md / 交接.md   ← 说明与交接（只读）
```

规矩写在同级的 `PERSONA.md` 里，改那个文件就是改她的人格。删掉会重建默认版。
详细的用盘说明在 `notes\硬盘指南.md`。
